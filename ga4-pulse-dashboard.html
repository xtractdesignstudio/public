Connect to Google Analytics

The dashboard reads GA4 directly from your browser with a read-only Google sign-in. Nothing is sent anywhere else.

This page is open as a local file. Google sign-in needs an http(s) address — serve the folder (python -m http.server 8080) and open http://localhost:8080/ga4-pulse-dashboard.html, or host it.
  1. In Google Cloud Console, enable Google Analytics Data API and Google Analytics Admin API.
  2. Create an OAuth client ID (type: Web application).
  3. Add this page's origin as an Authorized JavaScript origin:
  4. Paste the client ID below, then press Connect. For the demo data, your Google account must have added the GA4 demo account.
